⚙ Configuration API Google

L'API Google Custom Search est gratuite (100 requêtes/jour) et fonctionne directement dans le navigateur — aucun proxy, résultats fiables et précis.

1. Créez une clé API sur console.cloud.google.com → activer Custom Search API
2. Créez un moteur de recherche sur programmablesearchengine.google.com
3. Dans les paramètres du moteur, activez "Rechercher sur tout le web"
4. Copiez l'ID du moteur (cx) et collez-le ci-dessous
Quota gratuit : 100 vérifications/jour par projet
